# Orca on Debian Linux

## Description

[Orca](https://github.com/stablyai/orca) is the place for working with a fleet of agents (e.g. Grok Bot, Claude Code). Run any coding agent with your own subscription. Available on desktop, mobile and remote runtime.

### Notes

To access the Web client UI, you need to pair your browser using the url from the docker logs. `sudo docker logs orca`.
